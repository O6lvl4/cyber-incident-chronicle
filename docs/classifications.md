# 企業・攻撃の分類

分類は元の事案データに追加する参照データです。事案の会社名、公表日、影響、本文、一次資料、脆弱性カテゴリーは変更しません。

## 対象企業・業種・上場区分

- 事案から対象法人への参照と、法人ごとの業種・製造業の細分類を分離します。企業グループ全体の業種をすべての子会社へ引き継ぎません
- 上場区分は **被害対象法人自身** の確認日時点の情報です。発生当時の上場区分を表すものではありません。上場親会社があっても子会社を上場企業にしません
- 上場廃止・商号変更・会社分割では、同名の新法人と事件当時の法人を混同しません。解釈は各レコードの `note` と出典を参照します
- 企業以外の団体は対象外、確認資料が不足する法人は未確認・不明。IRページがないことだけでは非上場としません
- 複数法人にまたがる事案は、業種・製造細分類・上場区分が **同じ対象法人** に一致するときに抽出します。別々の法人や親会社の属性を組み合わせません。表示・集計は1事案1件です
- 業種・細分類は読み手が比較するための編集分類で、取引所の業種分類と同一とは限りません

## 攻撃・事象の種類と初期侵入経路

`attackKind` と `initialAccess` は別軸です。ランサムウェアは暗号化・恐喝などに使われる攻撃の種類であり、脆弱性や認証情報の悪用とは別に記録します。設定不備や非攻撃の障害も収録対象にあるため、すべてをサイバー攻撃と扱いません。

- 公表資料で確認できる内容だけを手動で分類。画面でキーワードから推定しません
- 攻撃・事象の種類は1事案につき主たる公表内容を1つ記録します。複数段階・複数手法の全件数ではありません。マルウェアはランサムウェア以外に分類したものです
- 各軸で confirmed / possible / unknown / notApplicable を別々に保存。片方が確認済みでも、もう片方を確認済みにしません
- 情報流出、障害、暗号化だけからランサムウェアを推定しません。公表が断定していない場合は可能性または不明を残します
- `unknown` は攻撃がないことを意味しません。汎用的な「不正アクセス」だけでは具体的な手法を特定しません
- 元資料の範囲・推定・留保は `note`、`sourceUrls`、元の `attackMethod` 本文から確認できます。分類の確認日と事案の公表時点を区別します

## フィルターと件数

「絞り込み」はモーダルで開きます。条件は選択するとすぐに適用され、下部の件数付き「結果を見る」で閉じて、元の一覧／タイムラインへ戻ります。閉じるボタン、Escape、背景クリックでも閉じられます。閉じるだけなら開いたボタンへ、結果を見るなら結果領域へフォーカスを戻します。選択済み条件は名前付きタグで確認・個別解除できます。侵入経路と確度は「詳細条件」、長い留保は「分類について」にまとめます。初期表示のタイムラインとデータは変えません。

従来の影響（OR）・流出確認状況・検索と、新しい分類条件（AND）を組み合わせます。選択したメーカー細分類に一致する対象法人だけを抽出します。「対象外」「未確認」は製造業の下位分類とは区別します。

確度は選択中の攻撃種別・侵入経路の各軸に適用します。両軸を選択すると両方が指定の確度である必要があります。両軸とも「すべて」なら攻撃種別の確度に適用します。

件数は現在表示している事案を母数とします。ランサムウェアの確認済み・可能性・攻撃種別不明を分け、国内全体の発生割合や企業の安全性を示す統計にはしません。元のSQL `incidents` テーブルは従来の事案正本です。

URLハッシュには業種、製造細分類、上場区分、攻撃種別、侵入経路、確度を保存します。不正な値は無視します。「すべて解除」は分類と既存条件を一緒に初期化します。ライブラリの脆弱性カテゴリーには企業分類を適用しません。

## 更新・検証

`src/data/entities/<entity-id>.json` が法人情報、`src/data/incident-entities.json` が事案から法人への参照、`src/data/attack-classifications/<incident-id>.json` が攻撃分類の正本です。新しいIDの追加後は `pnpm data:index` で型付きインポート一覧を更新します。生成済み一覧の手編集はしません。

新規事案には対象法人参照と攻撃分類が必要です。根拠が未確認でも、資料URLと不明である理由を残してください。`pnpm check` は網羅性、参照先、列挙値、確度の整合性、出典・日付を検証します。URL・組合せ・未知値・親子会社・集計の単体テストに加え、`pnpm test:ui` はフィルター操作、再読込、戻る/進む、ゼロ件、解除、スマホ表示を確認します。
