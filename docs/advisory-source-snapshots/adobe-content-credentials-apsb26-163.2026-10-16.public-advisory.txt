Summary
Adobe has released a priority 3 security update for Adobe Content Credentials SDK. This update addresses vulnerabilities rated high and medium that could result in security feature bypass, application denial-of-service, and arbitrary file system write.
Adobe is not aware of any exploits in the wild for any of the issues addressed in this update.
